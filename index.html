使用说明 & 数据口径

🎯 三种使用方式

  1. 智能匹配：输入品牌 + 产品品类，按预设模板一键回填筛选；
  2. 精细化筛选：手动组合行业 / 身份 / 内容形式 / 量级 / 人设 / 维度 / 人群 / 年龄 / 城市 / 性别 / 预算；
  3. 行业垂类：勾选「仅展示行业垂类博主」只看打标命中的垂类；不勾选则全量参与、垂类优先。

📤 导出

  • 「导出 CSV」：当前结果全部导出（匹配度 / 报价 / 画像）；
  • 「导出报告」：Top 30 + 品牌 / 品类 / 趋势 / 策略 / 选题，客户可直接使用。

📖 数据说明

  • 数据源：小红书蒲公英后台「博主刊例」全量 - 位博主（示例数据）；
  • 行业垂类依据博主一级内容标签打标（可在 js/config.js 校准映射）；
  • 报价为参考值，最终以蒲公英平台为准；粉丝画像来自平台公开数据。
